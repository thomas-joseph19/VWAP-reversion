Refactor `replay_single_trade`:
1. Track `units_open` (initially `config.units`).
2. Target 1 = `setup['daily_vwap']`. Target 2 = `setup['weekly_vwap']`.
3. Loop through rows:
    - If `units_open == 2` and Target 1 hit: Record Exit 1, `units_open = 1`, set `stop_loss_points = 0` (break-even).
    - If `units_open >= 1` and Target 2 hit: Record Exit 2, `units_open = 0`, return trade.
    - If Stop-loss hit: Record Exit for all open units, return trade.
    - If Session-end hit: Record Exit for all open units, return trade.
</action>
